`device_code

Mapping karyawan
1. Buka menu Karyawan.
2. Isi Employee code dan Nama lengkap.
3. Isi Identifier type dan Identifier value sesuai kartu RFID atau QR.
4. Setelah itu nama dan jabatan akan ikut muncul di respons absensi device.
U N T U K A D M I N
Cek cepat
Jika device tidak bisa kirim data: cek apakah statusnya sudah Enabled.
Jika respons
`401`
: biasanya API key salah atau device masih nonaktif.
Jika nama tidak muncul di layar device: cek mapping karyawan di menu Karyawan.
Jika waktu di layar salah: panggil lagi endpoint /api/v1/time.php.
Jika API key bocor: buka menu Devices lalu klik Reset key.
Kalau ingin cek server paling cepat dari terminal: curl "https://device.dsalute.id/api/v1/health.php"
